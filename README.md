# Sankadi Sheri Navratri

Create a beautiful, premium, fully responsive website for a Navratri event called “Sankadi Sheri”, inspired by the heritage culture of Ahmedabad’s old city pols (પોળ), traditional Gujarati architecture, and Navratri garba culture.

Event Details

Event Name: Sankadi Sheri
Event Type: Navratri / Garba Event
Venue: Alphonso Party Plot, Behind Sentosa Greenland Bungalow, Near Science City Circle, Ahmedabad, Gujarat – 372722, India
